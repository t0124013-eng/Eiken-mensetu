## 2. 採点サーバー（Apps Script）を作る
1. 学校アカウントで新しいスプレッドシートを作る（ここに結果が「記録」シートとして残ります）
2. 拡張機能 → Apps Script を開き、`Code.gs` を貼り付け、ファイルを追加して `Prompt.gs` を貼り付け
3. プロジェクトの設定 → スクリプト プロパティに
   - `GEMINI_API_KEY` … Google AI Studio で発行したキー
   - `GEMINI_MODEL` … 省略可（既定 `gemini-3.5-flash`）
4. エディタで `testGemini` を実行して動作確認（初回は権限の承認が出ます）
5. デプロイ → 新しいデプロイ → 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**（学校ドメイン内に限る場合は「〇〇内の全員」）
6. 発行された URL（…/exec）を `index.html` の `DEFAULT_GAS_URL` に貼る
   （または、アプリのトップ「先生用の設定」に入れて接続テスト）

※ URL が未設定・接続できないときは、自動で「Gemini に貼り付けて採点」する方式になります（APIなしでも使えます）。

## 3. 公開
GitHub Pages などにフォルダごと置きます。マイクを使うため https で開いてください。
推奨ブラウザは Google Chrome（音声認識がもっとも安定します）。

## 2級の流れ
自己紹介 → 問題カード → パッセージの黙読20秒 → 音読 → No.1（パッセージについて）→ No.2（3コマの説明、準備20秒）→ カードを裏返す → No.3 → No.4（Yes/No のあと Why? / Why not?）→ 採点。
2級は 音読・No.1〜No.4 各5点（内容3＋正確さ2）＋アティチュード3点 ＝ 28点（練習用の配点）。結果はスプレッドシートの「記録（2級）」シートに残ります。

## 準2級の流れ
自己紹介 → 問題カード → パッセージの黙読20秒 → 音読 → No.1（パッセージについて）→ No.2（イラストA：人物の動作）→ No.3（イラストB：状況）→ カードを裏返す → No.4・No.5（Yes/No のあと Why? / Why not? / Please tell me more.）→ 採点。
準2級は 音読・No.1〜No.5 各5点（内容3＋正確さ2）＋アティチュード3点 ＝ 33点（練習用の配点）。結果は「記録（準2級）」シートに残ります。

## 練習のしかた（トップで選択）
面接は自己紹介から始まります（入室・退室のあいさつやお礼はありません）。流れは「自己紹介 → 問題カード → 考える時間1分 → ナレーション2分 → No.1 → カードを裏返す → No.2〜No.4 → 採点」の7ステップです。
- **ガイドつき**：日本語の音声ガイドが自己紹介と考える時間の前に説明し、例文・チェックポイントを表示
- **本番モード**：ガイド・例文・ヒントなしで最後まで

## 評価のしくみ
- ナレーション 15点（内容8＋正確さ7）、No.1〜4 各5点（内容3＋正確さ2）、アティチュード3点 ＝ 38点
- 発音は評価しません。音声認識の句読点・同音語の誤認識は減点しないよう指示しています
- 評価シート：内容・正確さの講評、ブラッシュアップ例、間違ったところの修正版、次に使える表現、模範例
- 印刷・PDF保存ボタンあり。直近の記録は端末内にも保存
